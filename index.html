Google Classroom & Drive Explorer

ดึงชีทเรียน ใบงาน และเอกสาร PDF เข้าสมุดโน้ตในคลิกเดียว

ตั้งค่าการเชื่อมต่อ Google API (OAuth Client ID)

Google กำหนดให้ต้องใช้ Client ID สำหรับการเข้าถึงชีทเรียนใน Google Classroom ของโรงเรียนอย่างปลอดภัย

วิธีขอ Client ID ฟรี (ทำครั้งเดียวใช้ได้ตลอดไป):
  1. เข้าเว็บ Google Cloud Console แล้วกดสร้างโปรเจกต์ใหม่
  2. ไปที่เมนู APIs & Services แล้วเปิดใช้งาน: Google Classroom API และ Google Drive API
  3. ไปที่ OAuth consent screen เลือกประเภท External แล้วเพิ่ม Scope อ่านไฟล์
  4. ไปที่ Credentials ➡️ Create Credentials ➡️ OAuth client ID เลือก Web application
  5. ในช่อง Authorized JavaScript origins ให้ใส่ https://chitsnebula.github.io และ http://localhost:8080
  6. ก๊อปปี้ Client ID นำมาวางในช่องด้านบนนี้ แล้วกดบันทึกได้เลย!
