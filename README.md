# FarmNotes (GoodNotes Web Edition)

A powerful, responsive web-based digital notebook and PDF annotation application inspired by GoodNotes and Tesla's clean design philosophy.

## Features
- **Continuous Scroll & Palm-Rest Canvas**: Smooth multi-touch pinch zoom, 2-finger pan, and laser pointer.
- **Fast PDF Engine**: Instant opening (< 0.5s) with on-demand background page rendering and caching.
- **Annotation & Drawing**: Pen, pencil, highlighter, eraser, shapes, and lasso selection.
- **Image Cropper & Camera Shutter**: Integrated interactive 8-handle image cropper before and after insertion.
- **Google Lens Visual Search**: Crop and search any notebook content directly with Google Lens.
- **Offline Storage**: IndexedDB persistence for all notebooks, pages, strokes, and PDF assets.
- **Cloudflare Tunnel Support**: Easy local tunneling for remote sharing and mobile testing.

## Getting Started
Open `index.html` directly in a modern web browser, or serve locally:
```bash
python server.py
```
